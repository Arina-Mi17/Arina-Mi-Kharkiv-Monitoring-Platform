# Підключення Telegram-каналу до ARINA MI MONITOR без Cloudflare

Інтеграція працює через GitHub Actions. Перевірка каналу запускається приблизно кожні 5 хвилин. Cloudflare не потрібен.

## Як позначати дописи для сайту

У кінці допису в каналі додай обов’язкові теги:

`#НАМАПУ #ЦИВІЛЬНЕ`

Щоб допис з’явився ще й у спливаючому вікні на загальному маркері населеного пункту, додай один тег місця:

- `#МІСТО_ХАРКІВ`
- `#МІСТО_ДЕРГАЧІ`
- `#МІСТО_ЧУГУЇВ`
- `#МІСТО_БОГОДУХІВ`
- `#МІСТО_МЕРЕФА`
- `#МІСТО_ЗМІЇВ`
- `#МІСТО_БАЛАКЛІЯ`
- `#МІСТО_ІЗЮМ`
- `#МІСТО_ЛОЗОВА`
- `#МІСТО_КУПЯНСЬК`

До сайту потраплятимуть тільки дописи з обома обов’язковими тегами. Якщо додати тег міста, допис буде показаний у вікні відповідного загального маркера. Якщо тегу міста немає, він буде лише у стрічці. Не додавай ці теги до оперативних повідомлень про повітряні цілі, військові об'єкти, координати, маршрути, напрямки чи переміщення. Такі матеріали не призначені для публічної карти. Автоматичний фільтр додатково відкидає частину чутливих слів і координат, але він не може гарантувати розпізнавання всіх небезпечних формулювань — перед позначенням допису перевіряй його зміст.

## Налаштування в GitHub зі смартфона

1. Відкрий репозиторій: https://github.com/Arina-Mi17/Arina-Mi-Kharkiv-Monitoring-Platform
2. Відкрий **Settings** → **Secrets and variables** → **Actions**.
3. У вкладці **Secrets** натисни **New repository secret**.
   - Name: `TELEGRAM_BOT_TOKEN`
   - Secret: токен цього бота з BotFather.
   - Натисни **Add secret**.
   - Токен не надсилай у чат і не додавай у файли репозиторію.
4. Перейди у вкладку **Variables** → **New repository variable**.
   - Name: `TELEGRAM_CHANNEL_USERNAME`
   - Value: `kharkiv_info_chanel`
   - Натисни **Add variable**.
5. Відкрий **Settings** → **Actions** → **General**. У розділі Workflow permissions вибери **Read and write permissions** і збережи.
6. Відкрий вкладку **Actions** у репозиторії.
7. Вибери workflow **Telegram channel sync**.
8. Натисни **Run workflow** → **Run workflow**.

## Перевірка

1. Дочекайся зеленого статусу виконання workflow.
2. Опублікуй у каналі тестовий безпечний цивільний допис із тегами `#НАМАПУ #ЦИВІЛЬНЕ`.
3. Після наступного запуску workflow відкрий сайт і онови сторінку. Допис з'явиться у блоці **«Повідомлення з Telegram-каналу»**.
4. Оригінал допису відкривається за посиланням у картці.

## Важливі технічні умови

- Бот має залишатися адміністратором каналу, щоб Telegram надсилав йому дописи каналу.
- Цей варіант використовує Telegram `getUpdates`. Якщо для бота вже встановлений webhook на іншому сервері, Telegram не дозволить одночасно використовувати `getUpdates`; спершу потрібно з'ясувати, де він налаштований.
- GitHub Pages оновлюється після коміту даних; це не миттєвий стрім, зазвичай із затримкою до кількох хвилин.
- Інтеграція переносить лише текстові цивільні дописи. Фото, відео, геомітки й файли поки не копіюються.
- На сайті немає автоматичного розміщення точок за координатами. Мапа показує загальні населені пункти, а дописи — у стрічці.
