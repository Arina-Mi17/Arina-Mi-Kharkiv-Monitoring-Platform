# Автоматичне перенесення цивільних дописів Telegram на ARINA MI MONITOR

Перенесення налаштоване через GitHub Actions: перевірка каналу приблизно кожні 5 хвилин. Cloudflare і новий бот не потрібні.

## ЄДИНЕ обов'язкове налаштування

1. Відкрий репозиторій: https://github.com/Arina-Mi17/Arina-Mi-Kharkiv-Monitoring-Platform
2. Перейди в **Settings** → **Secrets and variables** → **Actions**.
3. У блоці **Secrets** натисни **New repository secret**.
4. У полі **Name** введи точно: `TELEGRAM_BOT_TOKEN`.
5. У полі **Secret** встав токен уже створеного бота з BotFather і натисни **Add secret**.

**Не надсилай токен у чат і не записуй його у файли репозиторію.** Мені він не потрібен. Ім'я каналу вже задане в коді, окрему змінну створювати не треба.

## Дозвіл GitHub Actions на запис

1. У репозиторії відкрий **Settings** → **Actions** → **General**.
2. Знайди **Workflow permissions**.
3. Вибери **Read and write permissions**.
4. Натисни **Save**.

## Увімкнення та перевірка

1. Відкрий вкладку **Actions**.
2. Вибери **Telegram channel sync**.
3. Натисни **Run workflow** → **Run workflow**.
4. Дочекайся завершення запуску. Якщо він зелений — перевірка Telegram API пройшла.
5. Для тесту опублікуй у каналі безпечне цивільне повідомлення з тегами `#НАМАПУ #ЦИВІЛЬНЕ`. Після наступного запуску перевір сайт.

## Як позначати дописи для сайту

До публічної стрічки потрапляють лише дописи, які містять обидва теги: `#НАМАПУ #ЦИВІЛЬНЕ`.

Щоб допис показався також у вікні загального маркера населеного пункту, додай один тег:
- `#МІСТО_ХАРКІВ`
- `#МІСТО_ДЕРГАЧІ`
- `#МІСТО_ЧУГУЇВ`
- `#МІСТО_БОГОДУХІВ`
- `#МІСТО_МЕРЕФА`
- `#МІСТО_ЗМІЇВ`
- `#МІСТО_БАЛАКЛІЯ`
- `#МІСТО_ІЗЮМ`
- `#МІСТО_ЛОЗОВА`
- `#МІСТО_КУПЯНСЬК`

Не позначай цими тегами повідомлення про повітряні цілі, військові об'єкти, координати, маршрути, напрямки або переміщення. Карта призначена для загальних цивільних повідомлень, не для оперативного відстеження. Автоматичний фільтр є додатковим, але не гарантує виявлення кожного небезпечного формулювання — перед публікацією перевіряй зміст.

## Що саме переноситься

- Тільки текст і підписи до медіа; самі фото, відео та файли не копіюються.
- Нові дописи з'являються після чергової перевірки й оновлення GitHub Pages, а не миттєво.
- Якщо для бота вже налаштований webhook, Telegram може відхилити `getUpdates` з помилкою 409. Не видаляй webhook навмання: спочатку треба з'ясувати, чи не використовує його інша інтеграція.
- Бот має залишатися адміністратором каналу.
